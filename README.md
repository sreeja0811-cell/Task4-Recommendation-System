# 🎬 Movie Recommendation System

## 📌 Project Overview

This project implements a simple recommendation system that suggests movies to users based on their preferred genre.

The system uses content-based filtering concepts by mapping user preferences to relevant movie categories and providing personalized recommendations.

This project was developed as part of the Artificial Intelligence Internship Program at MyDailyWork.

---

## 🌟 Features

* Personalized movie recommendations
* Genre-based filtering
* User-friendly command-line interface
* Multiple movie categories
* Fast recommendation generation

---

## 🛠 Technologies Used

* Python 3
* Dictionaries
* Conditional Logic
* Content-Based Recommendation Concepts
